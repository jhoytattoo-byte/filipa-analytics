✅ O QUE JÁ TEMOS (Funcionando na Produção .com.br)
Arquitetura de Pipeline:

Vision (IA) → Quant → Curador (Validação) → Judge (Decisão) → Learning (SQLite)

Frontend: filipaanalytics.com.br (Vercel) + Backend: filipa-analytics.onrender.com (Render)

Validação de Dados Reais (CRÍTICO):

backend/services/dataService.js (CRIADO): Consulta APIs reais na ordem: TwelveData → Binance → Polygon.io

Curador (curator.js): Compara o preço real da API com o preço da Vision. Se divergir > 50 pontos → BLOQUEADO.

Judge (judge.js): Implementado o RISK GATE com 3 regras:

Conflito de Tendência (ex: Venda + Tendência ALTA) = BLOQUEADO
Score não alinhado (ex: Compra + Score negativo) = BLOQUEADO
Dados reais inválidos = BLOQUEADO
Chaves de API Configuradas (Render):

TWELVEDATA_API_KEY (Fonte Principal)

GROQ_API_KEY, GEMINI_API_KEY, DASHSCOPE_API_KEY (IAs)

SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY (Auth)
